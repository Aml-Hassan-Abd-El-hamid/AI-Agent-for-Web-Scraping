Labeling outputs

Each labeller only ever writes their own append-only files, so pushing to a shared repo will not cause merge conflicts:

  • labels/<snapshot>/articles/<labeler>.jsonl: one line per article check
  • labels/<snapshot>/failures/<labeler>.jsonl: failed-link reviews
  • labels/<snapshot>/dropped/<labeler>.jsonl: dropped-link reviews
  • labels/<snapshot>/na/<labeler>.jsonl: N/A field reviews

The maintainer rebuilds the summary tables (manual_labeling_table.md, detailed_evaluation_table.md, etc.) by running python aggregate.py.
